A month of daily marketing posts. Each day = a concept, an on-image slogan

## How to use this file
1. Copy the **MASTER PROMPT** above, then paste the day's **Slogan + Prompt** after it — send both together to your image agent (Nano Banana / Gemini, GPT-Image, Flux, Midjourney, Ideogram — Ideogram/Flux are best at text).
2. **Text tip:** AI often garbles Hindi/English text. Best results = generate the *background/scene* from the prompt, then add the **slogan + logo in Canva** for crisp type. Or use Ideogram (strong at legible text).
3. Post the image with the day's **caption**.

### Brand kit (put in every prompt)
- Colors: teal `#0D9488`, deep navy `#0A2342`, white. Clean, modern, trustworthy.
- Logo: SafeTag wordmark, small, top-left or bottom.
- Format: **1080 × 1350 (4:5 portrait)** for best Instagram reach. (Use 1080×1080 square if you prefer.)
- Always include: `sftg.in` small at the bottom.
- People/settings: **authentically Indian** (faces, clothing, streets, homes, hospitals).

### Global negative prompt
`garbled text, misspelled words, warped logo, extra fingers, distorted faces, low-res, blurry, watermark, cartoonish when photoreal is wanted, cluttered layout`

### Base hashtags (add 3–4 day-specific ones each post)
`#SafeTag #EmergencyID #MadeInIndia #SafetyFirst #QRcode #MedicalID #Bharat #FamilySafety #sftgin`

## Bonus: reusable elements
- **Sign-off line for captions:** `SafeTag — Scan Karo, Jaan Bachao. 🆘 → sftg.in`
- **Recurring CTA button text (on image):** `Scan करें` · `Order करें` · `जानिए और → sftg.in`
